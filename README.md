# Student Demo

A beginner-friendly HTML project created to practise the fundamentals of web development and learn how to manage projects using Git and GitHub.

## About the Project

Student Demo is a simple webpage that displays a welcome message. It is a small learning project focused on understanding the basic structure of an HTML document.

## Features

- Displays a heading and welcome messages.
- Uses a standard HTML5 document structure.
- Includes character encoding and a responsive viewport setting.
- Requires no external libraries or dependencies.

## Technologies Used

- HTML5
- Git
- GitHub

## Project Structure

```text
Student-demo/
├── index.html
└── README.md
```

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/iamsayanmanna/Student-demo.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in any modern web browser.

## Learning Objectives

- Understand HTML document structure.
- Practise headings, paragraphs, and metadata.
- Learn basic Git and GitHub workflows.
- Build a foundation for future web development projects.
